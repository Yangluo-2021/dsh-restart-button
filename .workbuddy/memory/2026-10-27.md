### 插件 id 语义（改包名时别搞错）
`cordis.patch.yml` 里：
- `id:` = 插件身份，必须等于 `lib/index.js` 的 `export const name` = `dsh-restart-button`（**永不改变**）
- `name:` = npm 包说明符 = `@877701572-wq/dsh-restart-button`（发布时变）

`scripts/prepare-publish.mjs` 只改 `name:`，不动 `id:` —— 这是对的。
它原先只替换 README 里的 `@NPM_USER/`，**不处理** `github:<用户名>/` 那一处，
改名后会指向旧账号。**已修复**：脚本现在也替换 `github:xxx/` 形式的占位符。
